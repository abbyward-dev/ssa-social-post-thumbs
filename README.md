# SSA social post thumbnails

Small (about 300px) JPEG thumbnails used by the Organic Social Performance Google Sheet.

Google Sheets `=IMAGE()` can only load images from a public URL. These files are resized previews of posts already published or queued for SSA, Metal America, and Kit Culture social channels. They are not full-resolution originals.

If this repository is no longer needed, it can be archived or deleted.
